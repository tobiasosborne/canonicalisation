# checker/

**Purpose.** The independent certificate checker `canon-check` (spec §20, §3.2): a small program that decides whether a producer's certificate for a `CANONICAL_IMAGE` result is sound, by re-deriving the P1 search it describes from checkable group data. Slice S7 (`docs/slices/S7.md` §3.3–3.5) fills it with certificate format v0 (`CERT-0`); later versions add the enumeration, labeling and signed objectives and nested roots.

**Independence is the point.** The checker does **not** link against the `canon` library and does **not** include anything from `src/` or `include/`. It shares no code, headers, types or constants with the producer; the CMake target `canon-check` and the Makefile rule enforce this by giving it no include path and no library. Its components were written from the specification, not from the producer's sources (the S3 verifier `src/bsgs/verify.c` is a reference text for the list of conditions, nothing was copied). If the checker and the producer shared a bug, the check would prove nothing.

## Usage

```
canon-check FILE        FILE holds a CERT-0 certificate ('-' reads standard input)
```

Exit 0 and `ACCEPT <nodes>` (the number of node records) when every rule holds; exit 1 and `REJECT <reason>` naming the first violated rule; exit 2 on a usage or input error (and on exhausted memory). Acceptance means: under the trusted assumptions (compiler, runtime) the certificate's final claim is the profile P1 canonical image of its object under the group generated by its generators, with the stated witness. It does not establish the engine's memory safety (§20).

A certificate is produced by `canon-cli ... --certificate FILE` (canonical image of a subset or graph) or through the API option `canon_problem_options.certificate` and `canon_result_certificate`.

## Components (all in `checker/`, C17, standard library only)

| File | Content |
|---|---|
| `cc.h` | the shared declarations and the rejection reasons |
| `cc_reader.c` | big-endian byte reader (§4.1 U16/U32/B), checked allocation, dense permutation compose/inverse/bijection test (§3), byte order (§4.3) |
| `cc_chain.c` | stabiliser chain: deserialiser of the CHAIN layout, the verifier (below), membership by sifting (§9.2), orbits of a level's group ranked by least point (§7.1) |
| `cc_object.c` | CDAG-2 decoder for a set of atoms (tags `01`, `04`) and a coloured directed multigraph (tag `09`) (§4.1), the ATOM-TRANSPORT-1 action (§2.1), extensional equality (§4.2), the canonical encoder for the leaf image (§4.1–4.2) |
| `cc_refine.c` | ordered partition with `split` and individualisation (§7.1, §10), dense exact O-stage count signatures (§7.1) |
| `cc_check.c` | the certificate rules 1–7 below, replaying the tree node by node |
| `main.c` | file reading and the exit protocol |
| `tests/test_checker.py` | the harness: acceptance tiers and mutation rejection (below) |

The verifier (`cc_chain_verify`) checks, in this order, the conditions of spec §9.1 third paragraph plus nesting: structure (every index in range, base points distinct); (1) inputs and strong generators are bijections; (2) every strong generator equals the array its provenance record derives from the inputs (`INPUT a`, `INVERSE a`, `PRODUCT a b` with `a` acting first), evaluated by the checker; (3) level-`i` generators fix `b_0 … b_{i−1}`; nesting, the generators of level `i+1` are among those of level `i` as image arrays (without it a chain for `Sym(3)` of order 4 passes every other check, `docs/slices/S3-notes.md`); (4) orbit trees: `orbit[0]` is the base point, points distinct, every stored edge is `parent^s = point` for a level generator `s`, every position reaches the root; (5) orbit closure under the level generators; (6) the reconstructed transporter `t_b` sends the base point to `b`; (7) every Schreier residue `t_b s t_{b^s}^{-1}` sifts to the identity through the lower levels; (8) every input sifts to the identity from the root. (9) Terminal triviality is structural in the layout (the levels end where the list ends and the residue must be the identity); (10) the order is not needed.

## Certificate format `CERT-0` (restated from `src/search/certificate.h`)

All integers big endian (§4.1 `U16`, `U32`, `B`); `dense(p)` is `n × U32` images, `p[v] = v^p`; `0xffffffff` is NONE.

```
magic "CNC0" | U16(objective=0x0001) | U16(profile=0x0001) | U16(work_policy) | U16(encoding=0x0002)
| U16(order=0x0001) | U32(n) | B(CDAG-2 stream of x) | U32(k) | k × dense(generator)
| CHAIN(root: a verified chain of G whose inputs are the k generators)
| U32(m) | m × dense(automorphism)
| NODE(root)
| B(best trace) | B(best bytes) | dense(witness t) | U64(nodes explored)

NODE  = U32(depth) | U32(individualised atom, NONE at the root) | U32(sweeps) | sweeps × SWEEP
        | U8(kind) | LEAF (kind 00) or BRANCH (kind 01)
SWEEP = U32(k_O) | k_O × U32(cell size after O) | U32(f) | f × U32(F) | dense(u) | f × U32(M = F^u)
        | CHAIN(G rebased: base prefix M) | U32(k_G) | k_G × U32(cell size after G)
LEAF  = dense(t_L)
BRANCH = U32(target cell position) | U32(cell size) | cell size × CHILD
CHILD = U8(01) | U32(b) | NODE                               explored child b
      | U8(00) | U32(b) | U32(b') | U32(automorphism index)  pruned child b, representative b'
CHAIN = U32(n) | U32(depth) | depth × LEVEL | U32(g) | g × (U32(provenance node) | dense(generator))
        | U32(p) | p × (U32(kind) U32(a) U32(b)) | U32(i) | i × dense(input)
LEVEL = U32(base) | U32(r) | r × U32(orbit) | r × U32(parent point) | r × U32(parent generator
        position in the level's list) | U32(s) | s × U32(generator id)
```

The checker never depends on the engine's internal cell member order: children carry their points, and the cover of the cell is checked as a set.

## Rules (each a named reason on rejection; `docs/slices/S7.md` §3.4)

1. **Header and group.** Magic and the frozen IDs; `work_policy` is `0x0001`, `0x0002` or `0x0003` (S7b; the checker verifies the node count against the records and, under `0x0001`, that nothing was pruned, but does not re-derive which pruning policy produced a pruned tree); the object stream decodes (§4.1) with the header's `n`; generators are bijections; the root chain verifies and its inputs are byte-identical to the generator list, so it certifies exactly `⟨generators⟩` (`HEADER`, `DEGREE_MISMATCH`, `OBJECT_MALFORMED`, `OBJECT_UNSUPPORTED`, `GENERATOR_NOT_BIJECTION`, `CHAIN_*`, `ROOT_CHAIN_INPUTS`).
2. **Automorphisms.** Each listed `a` is a bijection that sifts in the root chain and satisfies `x^a = x` by the checker's own action and equality (`AUTOMORPHISM_NOT_MEMBER`, `AUTOMORPHISM_MOVES_X`).
3. **Root partition** from the checker's own initial keys (§7.1).
4. **Refinement replay.** Per node: depth and individualised atom as expected (`NODE_DEPTH`, `NODE_ATOM`); at least one sweep, and a sweep is the last one iff it did not increase the number of cells (`SWEEP_COUNT`). Per sweep: the O stage from the checker's own counts and `split`, sizes as recorded (`STAGE_O_SIZES`); `F` equals the singletons in partition order (`F_MISMATCH`); `u` is a bijection and a member of `G` (`U_NOT_BIJECTION`, `U_NOT_MEMBER`); `M = F^u` (`M_MISMATCH`); the rebased chain verifies (`CHAIN_*`), generates the same group as the root chain by mutual membership of the two generating sets (`REBASED_NOT_SAME_GROUP`), has base prefix `M` (`REBASED_BASE_PREFIX`) and `M[i]` is the least point of level `i`'s orbit (`M_NOT_MINIMAL`: by §7.2's constructive procedure and the uniqueness of the minimum, these conditions characterise `M = min F^G`); the orbits of level `f` (the pointwise stabiliser `G_M`) ranked by least point, pulled back through `u`, split the partition, sizes as recorded (`STAGE_G_SIZES`).
5. **Branch.** The recorded cell is the `(size, position)`-least non-singleton cell (`TARGET_CELL`, `BRANCH_AT_DISCRETE`); the child entries name every member of the cell exactly once (`CHILD_NOT_IN_CELL`, `CHILD_REPEATED`, `CHILD_MISSING`); for a pruned child `b` with representative `b'` and automorphism `a`: `a` fixes the node's prefix pointwise, `b'^a = b`, and `b'` is an explored child of the node (`PRUNED_AUTOMORPHISM_INDEX`, `PRUNED_AUTOMORPHISM_MOVES_PREFIX`, `PRUNED_AUTOMORPHISM_IMAGE`, `PRUNED_REP_NOT_EXPLORED`); the lemma of `docs/pruning-rules.md` then covers the pruned subtree.
6. **Leaf.** The partition is discrete (`LEAF_NOT_DISCRETE`); `t` equals the last sweep's `u` (`LEAF_T_MISMATCH`): there `F = L`, and the verified minimality of `M = L^u` makes `u` the unique minimiser of `L^G`, i.e. `t_L`; the image bytes are recomputed by the checker's own action and encoder and the key `(trace, bytes)` compared with the running minimum, the least `t` kept on an equal key.
7. **Final.** The recorded trace and bytes equal the minimum over the explored leaves (`FINAL_TRACE`, `FINAL_BYTES`); the witness is the least `t` attaining it (`FINAL_WITNESS`); the node count equals the number of node records (`NODE_COUNT`), and under policy `0x0001` no child was pruned (`PRUNED_UNDER_UNPRUNED_POLICY`; a pruned tree may name `0x0002` or `0x0003`, S7b); no trailing bytes (`TRAILING_BYTES`); a stream ending inside a field is `TRUNCATED`; a size beyond the checker's limits is `CAPACITY`.

## Tests

`checker/tests/test_checker.py` (standard library; `CANON_CLI`, `CANON_CHECK`; run by `make check` and `ctest`): every certificate of the T1 subset tier (every subgroup of `Sym(n)`, `n ≤ 4`, every subset) and the G1 digraph tier (`n ≤ 2`, every multiplicity vector in `{0,1,2}^(n²)`, two colourings) under the three work policies is accepted with the expected node count, plus a random sample on 5 and 6 points; the S7b case `{0}` under `Sym(4)` with implicit automorphisms; and one mutation per rule (a generator, an automorphism, a STAGE_O size, `u`, `M`, a rebased chain's orbit, a pruned child's automorphism index, a leaf `t`, the final trace and bytes, the witness, the node count, a deleted explored child, the work policy of a pruned certificate, a trailing byte, truncation) is rejected with the named reason. `CANON_E2E_FAST=1` (the sanitizer build) samples the tiers. Certificate sizes and node counts are printed for `docs/slices/S7-notes.md`.
