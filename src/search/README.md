# src/search

**Purpose.** Canonical search tree: target-cell choice, leaf map, trace/byte comparison, pruning with objective-specific coverage rules.

**Governing spec sections** (`docs/specification.md`, normative): §7 (profile P1), §7.2 (leaf map and proof), §7.3 (pruning), §8 (complete reference algorithms).

**Status.** Implemented in S1: `p1_tree.h`/`p1_tree.c`, the unpruned P1 tree for a subset (target cell by (size, position), every member individualised, rollback by snapshot), the §7.2 leaf map and the `(trace, CDAG-2 bytes)` minimum with the least attaining leaf witness, and the §11.1 NODE quota (`CAPACITY_LIMIT`). Workspace arrays are sized to a capacity that only grows. S2 generalises the search to a root object (`canon_p1_search_run`): the leaf acts on the root into reusable image storage (`canon_root_act_into`) and writes the stream by kind; the subset path is byte-identical to S1. Review fixes: the leaf compares its trace with the best one first (§7.2) and builds `t_L`, the image and its stream only when the trace is not greater (counters `leaves` and `images`), and every run ends by clearing the image's borrowed graph tables, so no workspace member points into a released object. Implemented in S4: `objectives.h`/`objectives.c`, the §8.2 consumers over the group's `enumerate` op (spec §8.1): `LEX_MIN_IMAGE` under `CDAG-BYTE-1` (the image's stream) and `SIMPLE-UPPER-1` (§4.4 key; the selected graph's CDAG-2 stream is returned too), with ties kept as the first found or, in deterministic mode, the least `g`; `TRANSPORTER_ONE` (object equality, stop at the first hit, empty only after exhaustion); `STABILISER` (hits sifted into a verified chain, non-members appended and the chain rebuilt and verified, at most log₂|A| rebuilds; `Group(A)` bytes); `TRANSPORTER_COSET` (one hit, then the complete stabiliser, `Group(A) || Perm(r₀)`); the §3 deterministic witness of the canonical image (least element of `A t`); and `canon_obj_check_witness` for `result_verify_witness` (membership by the backend, action by re-acting and comparing streams). One quota per solve counts every enumeration's visit calls. Every run clears the image's borrowed tables. Pruning arrives in S7 step 1 (below), certificates in S7 step 2. Implemented in S6 (`docs/slices/S6.md`): `canon_obj_labeling` (spec §3.1, §8.2 "Canonical labeling coset": `G′ = ρ⁻¹Gρ` through the group's `conjugate` op, `x′ = x^ρ` into the workspace's `prime` image (indexed when a graph), P1 on `D_n` for `t` and `c`, `λ = ρt`, then the complete stabiliser `A` of `x` under `G` and the payload `Group(A) || Perm(λ₀)`); `canon_obj_signed` (spec §8.4 and the §7.3 generator fast path: if every generator fixes `x` the first odd generator is the zero certificate, else `A = G` is even and `s = +1`; otherwise the stabiliser enumeration evaluates χ on every hit with the workspace's scratch, stops at the first odd one, and on exhaustion checks χ = +1 on `A`'s generators, runs P1 and returns `s = χ(t)` with `Group(A)`); `canon_obj_check_labeling` and `canon_obj_check_signed` for `result_verify_witness`. One quota covers the P1 NODE tokens and the enumeration visits. Implemented in S7 step 1 (`docs/slices/S7.md`, `docs/pruning-rules.md`): `canon_p1_search_run_policy`, the P1 tree under a work policy (§11.1 v2.1). Under `0x0002` the root builds `A_known` (`src/symmetry`) from the input generators that fix `x`; at a node whose prefix stabiliser `H_d` is nontrivial only the numerically least member of each `H_d`-orbit on the target cell is explored (the brief's lemma: the skipped subtrees carry the same leaf keys) and the quota counts only explored nodes; with `A_known = 1` the traversal is exactly the unpruned one. `canon_p1_search_run` stays the unpruned evaluator (§7.3 "The unpruned evaluator above is normative") and is what the labeling and signed consumers call, so they stay unpruned (§8.2); only `solve_canonical` in `src/api/api.c` passes the descriptor's policy. Counters `pruned`, `children`, `work_policy` and the `A_known` statistics. Certificates of the pruned search are S7 step 2. Tests: `tests/c/test_search_subset.c`, `test_search_graph.c`, `test_objectives.c`, `test_labeling.c`, `test_signed.c`, `test_prune.c`, `tests/python/test_e2e.py`.

**What may live here.** C17 sources and internal headers for this module only, no third-party code and no dependencies beyond the C standard library. Each rule implemented must cite its spec section in a comment (see `CLAUDE.md`). Golden constants must be derived from the rules, never copied (spec §20).
