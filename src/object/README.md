# src/object

**Purpose.** Native object adapters (subset, tuple, graph, DAG nodes, relations) with exact action, equality and validation.

**Governing spec sections** (`docs/specification.md`, normative): §6 (native objects, auxiliaries), §4.2 (extensional normalisation), §5 (semantic independence).

**Status.** Implemented in S1: the subset object `subset.h`/`subset.c` (bitset plus sorted member list, duplicate atoms merged, out-of-range atoms invalid, the spec §7.1 membership key, the §2.1 action `x^g` as a sorted list, equality). Implemented in S2: the coloured directed multigraph `graph.h`/`graph.c` (spec §4.1 import with normalisation: colour and label tables sorted by `(length, bytes)` = B order, duplicate `(source, target, label)` arcs combined by exact addition, zero multiplicities invalid, arcs sorted by `(source, target, B(label))`, total multiplicity computed with overflow checks per §11.1; CSR by source and CSC by target; the §2.1 action into reusable image storage that borrows the source's tables, total multiplicity and cached stream length and carries no index (`canon_graph_build_index` builds one on demand; `canon_graph_image_clear` drops the borrowed pointers; an imported graph is refused as image storage); extensional equality; the §4.1 simple undirected wrapper), and the root-object dispatch `object.h`/`object.c` (`canon_root` over subset and graph: §7.1 initial key, action into a reusable `canon_root_image`, stream write and exact stream size by kind). Slice S4 adds `canon_root_equal` (extensional equality by kind, used by the transporter and stabiliser consumers). Implemented in S5: `dag.h`/`dag.c`, nested objects of schema `EXT-DAG-1` as a record arena (tags 01-09; payloads are wire bytes; children precede parents), the §4.2 normaliser (bounded acyclicity pass, unreachable records discarded, bottom-up interning by exact tag, payload, children and counts with sets deduplicated and multiset counts added under the 64-bit limit, canonical leaf payloads for subgroups, cosets and graphs through the S4 writers and a verified chain, numbering by height then by record bytes with a field-wise comparator, the root last), the §2.1 action (atoms relabelled, `g⁻¹pg` for permutation leaves, `g⁻¹Hg` and `(g⁻¹Hg)(g⁻¹r)` for subgroup and coset leaves, then re-normalised), exact equality, the §11.1 image bound and the limits check; all scratch is grow-only (`canon_dag_scratch`). `object.h`/`object.c` gain the root kind `CANON_ROOT_DAG` (empty P1 initial key, action into the image's arena, general encoder) and `canon_root_import_stream`, which detects a set of atoms or a graph record after normalisation and builds the S1 subset or S2 graph exactly as the builders do (§7.1). Graph records below the root and the relations record are later slices. Tests: `tests/c/test_graph.c`, `test_signature.c`, `test_search_subset.c`, `test_search_graph.c`, `test_dag.c`, `test_dag_action.c`, `test_search_dag.c`, `tests/python/test_e2e.py`.

**What may live here.** C17 sources and internal headers for this module only, no third-party code and no dependencies beyond the C standard library. Each rule implemented must cite its spec section in a comment (see `CLAUDE.md`). Golden constants must be derived from the rules, never copied (spec §20).
