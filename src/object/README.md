# src/object

**Purpose.** Native object adapters (subset, tuple, graph, DAG nodes, relations) with exact action, equality and validation.

**Governing spec sections** (`docs/specification.md`, normative): §6 (native objects, auxiliaries), §4.2 (extensional normalisation), §5 (semantic independence).

**Status.** Implemented in S1: the subset object `subset.h`/`subset.c` (bitset plus sorted member list, duplicate atoms merged, out-of-range atoms invalid, the spec §7.1 membership key, the §2.1 action `x^g` as a sorted list, equality). Implemented in S2: the coloured directed multigraph `graph.h`/`graph.c` (spec §4.1 import with normalisation: colour and label tables sorted by `(length, bytes)` = B order, duplicate `(source, target, label)` arcs combined by exact addition, zero multiplicities invalid, arcs sorted by `(source, target, B(label))`, total multiplicity computed with overflow checks per §11.1; CSR by source and CSC by target; the §2.1 action into reusable image storage that borrows the source's tables, total multiplicity and cached stream length and carries no index (`canon_graph_build_index` builds one on demand; `canon_graph_image_clear` drops the borrowed pointers; an imported graph is refused as image storage); extensional equality; the §4.1 simple undirected wrapper), and the root-object dispatch `object.h`/`object.c` (`canon_root` over subset and graph: §7.1 initial key, action into a reusable `canon_root_image`, stream write and exact stream size by kind). Slice S4 adds `canon_root_equal` (extensional equality by kind, used by the transporter and stabiliser consumers). Tuples and nested DAGs follow in S5 (**M3**). Tests: `tests/c/test_graph.c`, `test_signature.c`, `test_search_subset.c`, `test_search_graph.c`, `tests/python/test_e2e.py`.

**What may live here.** C17 sources and internal headers for this module only, no third-party code and no dependencies beyond the C standard library. Each rule implemented must cite its spec section in a comment (see `CLAUDE.md`). Golden constants must be derived from the rules, never copied (spec §20).
