# src/encoding

**Purpose.** CDAG-2 wire encoder/decoder, canonical DAG numbering, order keys.

**Governing spec sections** (`docs/specification.md`, normative): §4.1 (wire grammar), §4.2 (canonical DAG references), §4.3 (comparison and keys), §4.4 (SIMPLE-UPPER-1), §9.4 (Group payload).

**Status.** Implemented in S1: wire primitives `wire.h`/`wire.c` (growable buffer, `U16`, `U32`, `B`, overflow-checked sizes, the §4.3 unsigned byte order) and `subset_stream.h`/`subset_stream.c` (the CDAG-2 stream of a top-level subset, a specialisation of the §4.2 numbering, plus its exact length). Implemented in S2: the `Nat` writer `canon_buf_put_nat` and `canon_nat_length` in `wire.c` (§4.1 shortest big-endian form), `graph_stream.h`/`graph_stream.c` (the CDAG-2 stream of a top-level graph, one height-0 record `09`; its exact length is measured once at import by `canon_graph_stream_measure` and cached on the graph), and `simple_upper.h`/`simple_upper.c` (the §4.4 `SIMPLE-UPPER-1` key for uncoloured simple undirected graphs, by binary search over the sorted arcs, so it needs no index; S4 adds `canon_simple_upper_in_class` and the minimum search under that order, `src/search/objectives.c`). Implemented in S4: `group_stream.h`/`group_stream.c`, `Perm(p)` (§4.1, moved support, source then target), the canonical `Group(H)` of §9.4 (rule 1 when `|H|` equals the product of the orbit factorials, computed in `uint64` with overflow detection, which decides the rule exactly while orders fit `uint64`; otherwise rule 2, the greedy sequence of least elements of `H \ K` from `src/coset/least.c` with `K` rebuilt and verified after each insertion), the labeling-coset payload `Group(H) || Perm(r₀)`, and a conservative input-derived size bound for the §11.1 output check. The multi-limb `canon_nat` is deferred (S4 notes). Implemented in S5: `cdag_encode.h`/`cdag_encode.c`, the general CDAG-2 encoder of a record arena and its exact length (the S1 subset and S2 graph streams stay as fast paths; `tests/c/test_dag.c` checks byte identity), and `cdag_decode.h`/`cdag_decode.c`, the strict §4.1 decoder for tags 01-09 with a reason per violation (bad magic, truncation, trailing bytes, out-of-domain atoms, forward references, unordered sets and multisets, zero or non-shortest `Nat`, malformed `Perm` and `Group` payloads, root range; `CANON_UNSUPPORTED_ACTION` for the encoding version byte, schema/action and the relations record; `CANON_CAPACITY_LIMIT` for a `Nat` above `uint64`), the payload readers shared with `src/object/dag.c`, stream import (decode, normalise, limits of the normal form, image bound) and the §4.2 validator (decode, normalise, encode, byte identity; it rejects unreachable records, a root other than the last, non-canonical orders, Group presentations, coset representatives and repeated or unsorted arcs, which import accepts). Tests: `tests/c/test_wire.c`, `test_nat.c`, `test_graph_stream.c`, `test_simple_upper.c`, `test_group_stream.c`, `test_dag.c`, `test_cdag_decode.c`.

**What may live here.** C17 sources and internal headers for this module only, no third-party code and no dependencies beyond the C standard library. Each rule implemented must cite its spec section in a comment (see `CLAUDE.md`). Golden constants must be derived from the rules, never copied (spec §20).
