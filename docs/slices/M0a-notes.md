## Readings taken

1. **Deterministic witness everywhere (§3).** As the brief's §2 states, with these consequences checked: for `TRANSPORTER_ONE` the quota may now be exceeded where the "any" mode completes (the stabiliser enumeration is part of the solve); for the labeling, `t` changes to `ρ⁻¹λ₀`, which `canon_obj_check_labeling` accepts since `ρt = λ₀` and `λ₀ρ⁻¹ = a λ ρ⁻¹ ∈ G`; for the signed nonzero route the sign is read off the replaced `t`, so no invariant is assumed.
2. **Mismatched transporter targets.** The library required the target to have the object's root kind (a set of atoms is a subset object, an empty multiset a nested one) and reported `INVALID_INPUT` otherwise (S4: §17 "mismatched target"). Found by the oracle on a T2 case (`t2-s11-000199-transporter_one`). The maintainer accepted the recommendation (13 October 2026): a target of another kind is admitted and the answer is the complete empty result, since a reference without this library's root kinds reports exactly that and the two must agree; `canon_problem_create_with_options` now checks the degree only, the oracle checks the ordinary transporter rule, and `tests/c/test_objectives.c` and `test_search_dag.c` pin the empty result.
3. **Quota 0.** The CLI reads `--max-nodes 0` as its default, so the runner cannot request a quota of 0; the generator never writes one. Noted in the runner's documentation.
4. **Raw DAG input (`refs/CASES.md` Part B).** Children may be listed after their parents; the wire needs them below. The runner emits the reachable records in child-first order with the root last, deduplicates set children and merges multiset pairs (the wire forbids duplicates); a `Group` leaf is written as a rule-2 presentation of its generators (rule 1 for the trivial group), which import normalises. None of this chooses an answer.
5. **Corruption switch `encoding` on T1.** T1 has no nested object, so omitting the §4.2 height ordering changes no T1 stream; the switch is shown on T2 (10 disagreements of 846). Recorded in the run README and the detailed plan.

## Independent review (19 October 2026)

Review of the M0a commits `9b1a665`, `616c03b`, `1d0d83b` (range `021d51c..1d0d83b`) at high effort, every finding re-checked against the code at `19d0c30` (after the S7/S7b and S8 reviews). ref-a was rebuilt at its sealed commit `9b1a665` in a scratch worktree and at `19d0c30` (gcc 13.3.0, `nice -n 19`), and both were run through `run_cases.py` on the golden cases, the whole default T1 and T2 files of 13 October and the T3 canonical-image cases, then compared with `compare.py`; the oracle was run on every record set.

**Verified and found sound.** The deterministic witnesses (brief §2): `TRANSPORTER_ONE` copies the hit into `s->g`, which the stabiliser consumer never touches (it uses `s->work`, `s->image` and, on the signed route only, `s->best`), and writes `r₀ = min A g` into `s->best` by `canon_coset_least` over the complete `A`; the chain is freed on every path; the second enumeration shares the visitor, so the one quota of §11.1 covers both, and the descent is counted in `stats.coset` (§8.3 "must appear in metrics"). The labeling's `t₀` is `canon_perm_compose(ρ⁻¹, λ₀)`, `ρ⁻¹` acting first, so `ρ t₀ = λ₀` by `(pq)[v] = q[p[v]]` (§3); `λ₀` is the `Perm(r₀)` of the payload (`s->work`), and `s->g` is free when it is reused for `ρ⁻¹`. The signed nonzero witness is replaced by `min A t` before χ is evaluated, so the sign is computed from the reported witness. The oracle imports only `closure`, `mul` and `inverse` from `checks/review_checks.py` (WP0.3), and its §9.4 writer, Perm, §4.4 key (pair order (0,1),(0,2),(1,2),(0,3),…), §4.2 height numbering and §8.4 lift follow the spec text. The runner computes no answer: it writes raw input streams (subset atoms sorted and deduplicated, tuple atoms one record per entry, DAG records child-first with the root last, set children deduplicated by index, multiset pairs merged by index), and every other record comes from the CLI. `compare.py` compares each of the six fields separately and `--plant` always changes the nibble (XOR with 1–15). The generator is deterministic, writes inputs only and omits every key the objective table marks absent.

## Maintainer decision D1 (19 October 2026): the deterministic witness of a certified zero

The maintainer decided review finding 3: in the deterministic witness mode a certified signed zero reports **the least image-array element of `A = Aut_G(x)` with `χ = −1`**, equivalently the least element of the coset `A⁺a`, `A⁺ = A ∩ ker χ` (index two in `A`), `a` any odd element of `A`. Spec v2.2 §3 (and the §8.4 reference algorithm) states it. This supersedes reading 4 of the brief (`M0a.md` §2 item 4: "Certified zero: the witness is the first odd automorphism of the frozen §8.1 traversal (or the first odd generator on the §7.3 fast path), as before"), which made the witness depend on the generator list. The `any` mode keeps returning the first verified odd automorphism.

- **Library** (`src/search/objectives.c`). The enumeration route no longer stops at the first odd hit in the deterministic mode: it keeps that hit, runs the §8.1 enumeration to exhaustion (the visits count against the one quota of §11.1, as spec v2.2 §3 says) and inserts only even hits, so the verified chain it ends with is exactly `A⁺`; the coset descent `canon_coset_least` then gives the least element of `A⁺a`. On the §7.3 fast path (`A = G`, nothing enumerated) `A⁺ = ker χ` is built as a verified chain from the Schreier generators of the transversal `{1, a}`, `a` the first odd generator: `s` and `a s a⁻¹` for an even generator `s`, `s a⁻¹` and `a s` for an odd one; the table and the chain go through `src/arena/mem.h` and are freed on every path. The admission plan charges the Schreier table and the chain's copy of its inputs (`plan_bytes`, "signed zero").
- **Tests.** `tests/c/test_signed.c`: on every T1 zero (both backends) and on every transported zero `x^h` the deterministic witness equals the brute-force least odd element of `A`; the review's example (`n = 3`, generators `[2,1,0]`, `[1,0,2]`, χ = (−1, −1), `x = ∅`) gives `[2,1,0]` in `any` mode and `[0,2,1]` in deterministic mode; on 24 random groups of degree 5 and 6 under the parity character the witness equals the least odd automorphism found by enumerating `G`, for the generator list as given, reversed, and with redundant generators (a product, an inverse, a repeat, the identity), on both routes. `test_faults.c` injects faults into both routes; `test_metrics.c` checks `peak ≤ plan` for the deterministic signed image on every T1 subset and for `Sym(6)` given by 40 generators. `tests/python/test_e2e.py` expects the least odd element; `tests/python/test_refs.py` checks the oracle's new rule on hand-made records.
- **Oracle** (`refs/oracle/oracle.py`). A deterministic zero record must carry the least odd element of `A`, by explicit enumeration.
- **ref-a** changes on the zero records whose old witness was not the least odd automorphism, so it is re-sealed (a third row in `refs/SEALS.md`). Measured against ref-a at `30bbdf0` through `run_cases.py` on the current corpus: identical on the golden cases (6) and on all 34 091 T1 records (0 of the 755 T1 zeros change: the T1 generators are greedy and start with the least elements); on the default T2 file (11 331 cases) exactly 92 of the 590 certified zeros change their witness and nothing else changes; the oracle accepts the new records on golden, T1 and T2 with 0 failures and rejects the old ones on exactly those 92 records.
