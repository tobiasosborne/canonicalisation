# Slice S7: certificates, the independent checker, and the first prune

**Status: reviewed 2 October 2026 (decisions D9-D11 in §6.1). Not yet ready to implement: one maintainer question remains (§6.2, the profile ID carried by the prune policy), and S8's reading must be folded in.** This slice introduces the first deviation from the unpruned reference traversal and the first trusted-boundary artefact. The pruning lemma in §3.1 and the certificate rules in §3.3 are the parts to read.

**Goal.** The canonical-image objective can emit a certificate that an independent checker (no code shared with `src/`) verifies: it re-derives every refinement step from checkable group data, re-verifies every automorphism used for pruning, confirms that every child of every node was either explored or validly pruned, and confirms the final minimum. The search gains one prune, orbit pruning by verified automorphisms fixing the node's prefix, using explicit automorphisms only (input generators verified to fix `x`, source i of §3.1). Implicit automorphism discovery from equal leaf keys (source ii) is deferred to its own slice, S7b (§6.1, D11). Pruned and unpruned runs give identical traces, bytes and witnesses on every tier.

Normative text: `docs/specification.md` v2.1 (2 October 2026; v2.0 is the reviewed baseline) (cited §x): §§3.2, 7.1, 7.2, 7.3, 8.2, 9.1, 9.2, 11.1, 14.3 (R2), 17, 20. Process: `docs/detailed-implementation-plan.md` §0, §0a, §7 (WP4.5, WP4.7). Prerequisites: S1–S6 landed.

## 1. Scope

In scope:

- `src/symmetry/`: the verified automorphism subgroup `A_known` (a chain built from automorphisms verified by membership and `x^a = x`; in S7 its only source is the input generators that fix `x`), prefix-stabiliser orbit computation. Implicit automorphism discovery is deferred to S7b.
- `src/search/p1_tree.c`: orbit pruning under the lemma of §3.1 for `CANONICAL_IMAGE` only; a `prune` switch in the problem options (default on; off reproduces the reference traversal) and counters for nodes, leaves, pruned children, automorphisms inserted.
- `src/search/certificate.c`: certificate v0 emission for `CANONICAL_IMAGE` on subset and graph roots (§3.3).
- `checker/`: the independent checker `canon-check` (§3.4).
- API: `canon_result_certificate(result, &bytes, &len)`, a `certificate` flag in the problem options; evidence mode `TRUSTED_ENGINE` versus `CHECKED_CERTIFICATE` recorded on the result (§3.2).
- CLI: `--prune on|off`, `--certificate FILE`; `canon-check FILE` exit 0 on accept, 1 on reject with a reason, 2 on usage.
- Tests: pruned versus unpruned byte identity on every tier; checker accepts every emitted certificate; mutation rejection; `docs/pruning-rules.md` with the lemma.

Out of scope: implicit automorphism discovery from equal leaf keys (source ii of §3.1; slice S7b, §6.1 D11); pruning for any objective other than the canonical image (§8.2: image-only pruning never proves a full stabiliser); certificates for enumeration, labeling or signed objectives (v1); DAG roots in certificates (v1); trace-prefix domination and bound pruning (§7.3, later); the Lean checker (M1/M4).

## 2. Definitions

The P1 tree of `(x, G)`: nodes are ordered sequences `S = (a_1, …, a_d)` of individualised atoms; the node's ordered partition `π_S` is the result of the §7.1 refinement loop after individualising `a_1, …, a_d` in order from the root partition; its trace `τ_S` is the concatenation of the tokens of the nodes on the path; if `π_S` is discrete the node is a leaf with full list `L_S`, transporter `t_S = t_{L_S}` and key `κ_S = (τ_S, bytes(x^{t_S}))`; otherwise its target cell is `C_S` (least `(size, position)` among non-singleton cells) and its children are `S·b` for `b ∈ C_S`.

For `h ∈ G` write `S^h = (a_1^h, …, a_d^h)`.

**Tree equivariance (§7.2, proved in S1's reading 1 and checked on every tier).** For `h ∈ G`: `π_{S^h}(x^h) = π_S(x)^h` cellwise in order, `τ_{S^h}(x^h) = τ_S(x)`, `C_{S^h}(x^h) = C_S(x)^h`, and at leaves `t_{L^h} = h^{-1} t_L`, so `(x^h)^{t_{L^h}} = x^{t_L}`.

## 3. Design

### 3.1 Pruning lemma and rule

**Lemma (orbit pruning by prefix-fixing automorphisms).** Let `a ∈ Aut_G(x)` and let `S = (a_1, …, a_d)` be a node with `a_i^a = a_i` for all `i ≤ d`. Then for every `b ∈ C_S`, the subtrees rooted at `S·b` and `S·b^a` have the same multiset of leaf keys, and for every leaf `L` below `S·b` the leaf `L^a` below `S·b^a` has `t_{L^a} = a^{-1} t_L` and the same image `x^{t_{L^a}} = x^{t_L}`.

*Proof.* Since `x^a = x`, equivariance with `h = a` maps the tree of `x` to itself: node `T ↦ T^a`, with equal traces, and `S^a = S` because `a` fixes the prefix pointwise. The child `S·b` maps to `S·b^a`, and `b^a ∈ C_S` because `C_{S^a} = C_S^a = C_S` (the target cell of `S` is mapped to itself as a set). Leaves below `S·b` map bijectively to leaves below `S·b^a` with equal traces; the image equality is the leaf-map identity with `h = a`. ∎

**Rule.** At a node `S`, let `A_S ≤ A_known` be the pointwise stabiliser of `(a_1, …, a_d)` in the verified subgroup `A_known` (a chain suffix after rebase to the prefix; rebase without verification as in S3). Partition `C_S` into `A_S`-orbits (union-find over `A_S`'s generators). Explore exactly one child per orbit, the least `b` of each orbit in cell order, and record the others as pruned with the orbit representative. By the lemma the explored children's key sets together cover every key in the node's subtree, so the minimum over the explored children equals the minimum over all children. **Scope:** this covers the canonical image's key minimum. It does not cover the deterministic witness (the least `t` over all leaves attaining the minimum key is not preserved: pruned leaves can carry smaller `t`); with `witness_mode = DETERMINISTIC` the witness is still computed from the complete stabiliser as in S4, so it is unaffected. With `witness_mode = ANY` the pruned run may return a different valid witness; the tests compare traces and bytes only in that mode and additionally compare witnesses in deterministic mode.

**Automorphism sources.** (i) Input generators that fix `x` (checked by action); this is the only source in S7. (ii) *For S7b (deferred, §6.1 D11; not implemented in S7):* implicit automorphisms: when a leaf `L` has `κ_L = κ_best` (equal trace and equal bytes), then `x^{t_L} = x^{t_best}` so `a = t_L t_best^{-1}` satisfies `x^a = x`; verify by exact action and membership before inserting into `A_known` (§7.3 "Verify implicit automorphisms by exact membership and object equality before publication"). (iii) Nothing else; R2 (§14.3) forbids any contribution that is not a verified automorphism. `A_known` is maintained as a verified chain (`canon_bsgs_insert_verified`). `A_known ≤ A` always; it need not be complete, and the lemma does not require completeness.

**Interaction with the quota (§6.1 D9; spec §11.1 v2.1).** The logical work quota counts the nodes of the traversal fixed by the profile's policy for the objective (P1 NODE tokens plus §8.1 enumerator visits; one quota per solve, default 2^20). A pruned run counts the nodes explored under the fixed sequential prune policy; no count-only traversal of pruned subtrees is made. A pruning policy that changes the count carries its own profile ID (PROFILE-EQUIV), so the prune policy is identified by its profile ID, and parallel modes must reproduce the sequential count (S8 ties it to the problem identity). With `prune` off the count is P1's, unchanged. This is §11.1 v2.1's rule, not a deviation from it (v2.0's "fixed reference traversal (including regions physically pruned)" wording is replaced in v2.1).

### 3.2 Search changes

- Node loop unchanged. After the target cell is chosen: if pruning is on and `A_known` is nontrivial, rebase `A_known` to the node prefix (no verification), take the suffix, compute orbits on `C_S`, iterate representatives.
- At the root: insert into `A_known` the input generators that fix `x` (source i), each verified by action.
- At a leaf: compare with the incumbent. (Deriving, verifying and inserting the implicit automorphism on an equal key is source ii, deferred to S7b.)
- Counters: nodes explored, leaves, pruned children, automorphisms inserted, rebases.
- Tests: on every tier, pruned and unpruned runs agree on trace and bytes (both backends); in deterministic witness mode they agree on witnesses too; node counts logged; a case with a large automorphism group (empty subset under `Sym(6)`, the §7.4 empty-subset case under `Sym(2)`) shows the node count drop to the orbit count.

### 3.3 Certificate v0 (`src/search/certificate.c`)

A certificate is a byte stream (versioned, `CERT-0`) that lets the checker re-derive the search without trusting the engine:

```
magic "CNC0" | U16(objective=0x0001) | U16(profile=1) | U16(encoding=2) | U16(order=1)
| U32(n) | B(input stream x in CDAG-2) | U32(k) | k dense generators of G (U32 images)
| ROOT CHAIN: a verified chain for G in the serialised form of §3.5
| U32(automorphism count) | automorphisms: dense arrays, in insertion order
| node records in DFS order
| FINAL: B(best trace) | B(best bytes) | witness t (dense)
```

Node record: `U32(depth)`, `U32(individualised atom or NONE)`, then for each sweep: `U32(k_O)` cell sizes after O, then the G-stage data `GSTAGE: U32(|F|) F | u (dense) | M (= F^u) | REBASED CHAIN for G with base prefix M (§3.5) | U32(k_G) cell sizes after G`; then `LEAF: t (dense)` or `BRANCH: U32(cell position) U32(cell size) U32(child count)` followed by one child entry per cell member in cell order: `EXPLORED` (its node record follows recursively) or `PRUNED U32(representative b') U32(automorphism index)` where the named automorphism `a` satisfies `b'^a = b` (so `b` is in `b'`'s orbit under the prefix stabiliser; the checker needs only one automorphism per pruned child, not the whole orbit computation).

Sizes: a rebased chain per G stage per node is large; v0 accepts this (decided, §6.1 D10) (§20: "Certificates can themselves be large"); report certificate bytes and check time in tests.

### 3.4 Checker (`checker/`)

Independent C17 program; shares no source with `src/` (CMake and Makefile already enforce no include path). It needs its own: wire reader; dense permutation compose/inverse/apply; chain deserialiser and **verifier** implementing the §9.1 list plus the nesting condition (S3's `verify.c` is the reference text, but the checker's code is written separately; the ten conditions are listed in `checker/README.md`); sifting; union-find; ordered partition with `split`; the P1 O stage for graphs (its own CSR from its own decoded graph) and the empty O stage for subsets; CDAG-2 decoder for subset and graph streams (tags `01`, `04`, `09` only in v0) and an encoder for the leaf image; byte comparison. Nested roots are rejected as unsupported in v0.

Rules checked, each a named reason on failure:

1. Header IDs are the frozen ones; `n` matches the stream; generators are bijections; the root chain verifies and generates exactly `⟨generators⟩` (every generator sifts; every chain generator is a product of inputs by provenance).
2. Each automorphism `a` is a member (sifts in the root chain) and `x^a = x` (checker's own action and equality).
3. Root partition from the checker's own initial keys (§7.1).
4. For each node, replay the refinement loop: O stage from the checker's own counts and `split`; the recorded `STAGE_O` sizes must match. G stage: `F` must equal the singleton list in partition order; `u` must sift in the root chain and satisfy `F^u = M`; the rebased chain must verify, generate the same group as the root chain (mutual sifting of generators), and have base prefix `M`; **minimality:** for each `i`, `M[i]` must be the least point of level `i`'s orbit (§7.2 constructive procedure: the least image is obtained greedily, and uniqueness of the minimum makes the greedy choice forced); orbits of `G_M` are the orbits of the chain suffix after `|M|` levels, ranked by least point; the pulled-back split must reproduce the recorded `STAGE_G` sizes. Loop termination and the final no-change sweep exactly as §7.1.
5. At a branch: the recorded cell is the `(size, position)`-minimal non-singleton cell; the child entries cover every member of the cell exactly once in cell order; for each `PRUNED b` with representative `b'` and automorphism `a`: `a` fixes the node's prefix pointwise and `b'^a = b`, and `b'` is an explored child of this node (the lemma then applies).
6. At a leaf: the partition is discrete; `t` sifts and `L^t` is the lexicographic minimum of `L^G`, checked with the same minimality rule as 4 using a rebased chain supplied in the leaf record (or by re-using the last G-stage chain when `L = F`, which is the case at a discrete node after its final sweep: state and check this); the image bytes are recomputed by the checker; the key is compared with the running minimum.
7. Final: the recorded best trace and bytes equal the minimum over all explored leaves; the witness equals the recorded leaf's `t` (any-witness mode) and sends `x` to the image.

The checker's acceptance means: under the trusted assumptions (compiler, runtime), the engine's claim is the P1 canonical image of `x` under `⟨generators⟩`. It does not establish engine memory safety (§20).

### 3.5 Serialised chain

`U32(depth)`, then per level `U32(base) U32(orbit_len) orbit[] parent_point[] parent_gen[] U32(gen_count) gen_ids[]`, then `U32(gen_total)` dense generators and `U32(prov_count)` provenance nodes `(kind, a, b)`, then the `U32(input_count)` inputs. The checker re-derives every generator from provenance down to the inputs and checks the inputs against the certificate's generator list (root chain) or against the root chain's generators (rebased chains).

## 4. Tests

## 6. Decisions (2 October 2026)

### 6.1 Decided

- **D9 (former open point 1, quota under pruning).** The quota under pruning counts the nodes explored under the fixed sequential prune policy; the policy is identified by the profile ID; parallel modes must reproduce the sequential count (S8 ties it to the problem identity). This is spec §11.1 v2.1: the quota counts the nodes of the traversal fixed by the profile's policy, and a pruning policy that changes the count carries its own profile ID. No separate count-only traversal of pruned subtrees.
- **D10 (former open point 2, certificate size).** Certificate v0 embeds a rebased chain per G stage, keeping the checker small; the checker does not own a Schreier–Sims. The format of §3.3 and §3.5 stands as drafted.
- **D11 (former open point 3, implicit automorphisms).** Implicit automorphism discovery from equal leaf keys (source ii) is deferred to its own slice, S7b, so S7 stays reviewable. S7 uses explicit automorphisms only (source i). The soundness argument for source ii stays in §3.1, marked for S7b.

### 6.2 Remaining before implementation

1. **The prune policy's profile ID.** D9 and §11.1 v2.1 require the prune policy, which changes the quota count, to carry its own profile ID. The brief does not yet name it, nor say (a) which profile ID a `prune`-on result reports, (b) whether the certificate header's `U16(profile=1)` (§3.3) records that ID instead of P1's, and (c) whether `prune` stays default on (§1), which would make the new profile, not P1, the default.
