# Slice S4: coset enumeration objectives and canonical group bytes

**Goal.** The four enumeration objectives of spec §8 are available through the public API and the CLI, built on the disjoint coset enumerator of §8.1 over the S3 chain: `LEX_MIN_IMAGE` under `CDAG-BYTE-1` and `SIMPLE-UPPER-1`, `TRANSPORTER_ONE`, `STABILISER` and `TRANSPORTER_COSET`. Group answers are returned as canonical `Group(H)` bytes (§9.4) and coset answers as `Group(H) || Perm(r₀)`. `canon_result_verify_witness` works. The deterministic witness of §3 is available as an option for the canonical-image objective. The end-to-end test checks every objective against brute-force enumeration in Python on the T1 tier and on random groups.

Normative text: `docs/specification.md` v2.0 (cited §x): §§3, 3.2, 4.1, 4.3, 4.4, 8.1, 8.2, 8.3, 9.2, 9.4, 11.1, 17. Process and interfaces: `docs/detailed-implementation-plan.md` §0, §0a, §2.4, §5 (WP2.6, WP2.7), §7 (WP4.4). Prerequisites: S1–S3 landed. The S1 §2 rules and the conventions enforced in the S1–S3 reviews apply (one checked allocator, checked arithmetic, shared sort, atomic refcounts, grow-only workspaces, no borrowed pointers after a run, immutable contexts).

## 1. Scope

In scope:

- `src/coset/`: the §8.1 enumerator with consumer callbacks, cancellation poll and the logical work quota; the constrained least-element descent shared with §9.4.
- `src/encoding/group_stream.c`: `Perm(p)`, `Group(H)` (rules 1 and 2 of §9.4) and the coset payload `Group(H) || Perm(r₀)`.
- `src/search/objectives.c`: the consumers of §8.2 for minimum, transporter one, stabiliser and transporter coset; the deterministic witness of §3 for the canonical image.
- `src/api/`: a problem builder taking a target object and options; result accessors for the group payload, the minimum key and the transporter; `canon_result_verify_witness`.
- `tools/canon-cli.c`: subcommands `min`, `transporter`, `stabiliser`, `transporter-coset`; the FORMAT gains the `group_hex` field (detailed plan WP0.2), with `refs/compare/FORMAT.md` and `compare.py` updated.
- Tests: C unit tests; `tests/python/test_e2e.py` tiers for every objective against brute force.
- READMEs; `docs/slices/S4-notes.md`.

Out of scope: nested objects and the decoder (S5), labeling cosets and signed images (S6), `CONSTRAINT_ONE/ENUM` (needs a registered predicate API; scheduled with S6 or later), pruning and bounds (§8.3 beyond the bottom bound; S7), multi-limb orders (`canon_nat`; see §3.5), batch solve (S8), performance work on the descent (M5).

```c
typedef struct canon_problem_options { canon_witness_mode witness_mode; } canon_problem_options;

canon_status canon_problem_create_with_options(canon_context *, const canon_group *,
    const canon_object *object, const canon_object *target, canon_objective, canon_profile,
    canon_encoding, canon_order, const canon_capacity *, const canon_problem_options *,
    canon_problem **out);

/* spec 9.4: canonical Group(H) bytes (STABILISER) or Group(A) || Perm(r0) (TRANSPORTER_COSET);
 * NULL/0 unless subgroup_verified && stabiliser_complete (and transport_exhausted for a coset). */
const uint8_t *canon_result_group_bytes(const canon_result *, size_t *length);
/* spec 4.4: the SIMPLE-UPPER-1 key of the minimum when that order was requested; else NULL/0. */
const uint8_t *canon_result_order_key(const canon_result *, size_t *length);
/* spec 8.2: for TRANSPORTER_ONE/COSET, one g with x^g = y (NULL if none or not exhausted). */
const uint32_t *canon_result_transporter(const canon_result *, uint32_t *degree);
```

`canon_result_witness` continues to return the witness of the canonical image and, for `LEX_MIN_IMAGE`, the `g` attaining the minimum (least `g` among all attaining it when `witness_mode` is deterministic, else the first found by the reference traversal). `canon_result_bytes` returns the minimum image's CDAG-2 stream for `LEX_MIN_IMAGE` with either order (§4.4: "return the selected graph in CDAG-2 plus its order key"). `canon_result_verify_witness` (§17): membership of the witness in `G` by the backend's `contains` and exact action `x^t = c` by re-acting and comparing streams; it never asserts canonicity. Result flags per objective (§3.2): minimum → `minimum_proved`, `witness_valid`, `encoding_complete`; transporter one → `witness_valid` (hit) or `transport_exhausted` (empty); stabiliser → `subgroup_verified`, `stabiliser_complete`; transporter coset → the union, with `transport_exhausted` meaning the empty case was proved. Statuses: `COMPLETE`; `CAPACITY_LIMIT` when the enumeration's logical work quota is exceeded (§3.5); `UNSUPPORTED_ACTION` for `SIMPLE-UPPER-1` on an object outside §4.4's class (empty colours and labels, no loops, one unit arc each way) or for an order/objective combination not listed here; `INVALID_INPUT` for a missing or mismatched target.

## 3. Design

### 3.1 Constrained least element (`src/coset/least.c`) (§9.4, §8.1)

`canon_coset_least(J_chain, r, constraints, out)`: the lexicographically least image array in the coset `J r` subject to `k` point constraints `v_i ↦ c_i` (possibly none). Descend over points `v = 0, 1, …, n−1`: maintain the current coset `J' r'` where `J'` is the pointwise stabiliser in `J` of the points already fixed (a chain for `J` rebased to the prefix of fixed points) and `r'` a representative; the images of `v` under `J' r'` are `(v^{J'})^{r'}`; choose the least image `c` (or the constrained `c_v` if `v` is constrained, returning "empty" if it is not among the images); pick `j ∈ J'` with `v^j r' = c` from the transporter of `v`'s orbit; set `r' ← j r'`; fix `v`. After all points, `r'` is the least element. Rebase per step is the S3 cost model (one rebuild per fixed point, no verification of internal chains); record it as M5 work. Tests: against brute force over explicit element tables on T1 groups with random cosets and random constraint sets; the §7.4 coset payload (`H = 1`, `r = [1,0]`, least element `[1,0]`).

Three uses: `t_b` in the enumerator (constraint `a ↦ b`, coset `H·id`); `r₀` of a coset `A g`; and the §9.4 rule-2 descent (below).

### 3.2 Enumerator (`src/coset/enumerate.c`) (§8.1)

```
visit(H, r):                    # region H r; H given as a chain, r as a dense array
    nodes += 1; if nodes > quota: abandon with CAPACITY_LIMIT
    if H is trivial: return consume(r)
    a = least point moved by H  (least v whose orbit under H's generators is not {v})
    rebase H so that its base starts with a; orbit = a^H in increasing order
    for b in orbit:
        t_b = canon_coset_least(H, id, {a ↦ b})
        child = suffix of the rebased chain after a   # H_a
        visit(child, t_b · r)
        if consume asked to stop: return STOP
```

The quota counts `visit` calls (§11.1: "a logical work quota … counts the fixed reference traversal"), so `CAPACITY_LIMIT` is a function of the input and the descriptor. Cancellation is polled per node. Products use `(pq)[v] = q[p[v]]`: `t_b r` means `t_b` first, then `r`; test on non-commuting elements that the visited leaves are exactly the elements of `G` (as a set, and each exactly once) on T1 groups. No pruning (§8.1 "zero pruning"; §8.3 "the reference uses the bottom bound").

### 3.3 Consumers (`src/search/objectives.c`) (§8.2)

- **Minimum.** Key of `x^r` under the requested order: the CDAG-2 stream (`CDAG-BYTE-1`) or the `SIMPLE-UPPER-1` key (which requires the §4.4 class, checked at problem creation). Keep the least key; on an equal key under deterministic witness mode keep the lexicographically smaller `r`. Exhaust all leaves. `minimum_proved` is set only on exhaustion.
- **Transporter one.** `x^r = y` by object equality (not by stream comparison, which costs more); stop at the first hit with the witness `r`. Empty only after exhaustion (`transport_exhausted`).
- **Stabiliser.** Each hit `x^r = x` is sifted through the current verified chain for `A_known`; a non-member is appended as a generator and the chain rebuilt and verified (the number of rebuilds is at most `log₂|A|`). After exhaustion `A_known = A` exactly (§8.2: "Exhaustion proves every member of A was inserted and no other one was"). Return `Group(A)` bytes and set `subgroup_verified`, `stabiliser_complete`.
- **Transporter coset.** Find one `g` (as transporter one); if none, exhausted empty. Else run the stabiliser consumer for `x` to completion (a second enumeration) and return `A g` as `Group(A) || Perm(r₀)` with `r₀ = canon_coset_least(A, g, ∅)`. (§8.2: "All solutions r satisfy r g⁻¹ ∈ A".)
- **Deterministic witness for the canonical image** (§3). With `witness_mode = DETERMINISTIC`, after P1 returns `c` and `t`, run the stabiliser consumer to obtain `A`, then `t_det = canon_coset_least(A, t, ∅)`. Test on T1 that this equals the least leaf witness of the unpruned tree (S1 reading 1), so the two definitions are checked against each other, not assumed.

### 3.4 Group and coset bytes (`src/encoding/group_stream.c`) (§9.4, §4.1)

- `Perm(p)`: `U32(s)` then `s` pairs `U32(i) U32(p[i])` over the moved points in increasing `i`.
- Rule 1: compute the orbits of `H` (union-find over its generators); compute `∏ |O_i|!` in `uint64` with overflow detection; if it overflows it exceeds `|H|` (which fits `uint64` by S3's admission), so rule 1 fails; if it equals `|H|`, encode `01 || U32(k)` followed by each non-singleton orbit as `U32(size) U32(points…)`, points increasing, orbits by least point. Trivial `H` is `01 00000000`.
- Rule 2: `K = 1` (an empty chain); repeat: `g = least element of H \ K` by descent over point images: at each level the candidate branch is the coset `C = J r` of elements of `H` with the images chosen so far; discard `C` iff `r ∈ K` and `J ≤ K` (every generator of `J` sifts in `K`), choose the least surviving image, recurse; if no branch survives `K = H` and the sequence is complete. Append `g` to `K`'s generators, rebuild and verify. Encode `00 || U32(k) || Perm(g_1) … Perm(g_k)`. Assert `2^k ≤ |H|` in tests.
- Coset `H r`: `Group(H) || Perm(r₀)` with `r₀ = canon_coset_least(H, r, ∅)`.
- Tests: the four §7.4 payloads (`Group(1)`, `Group(Sym(2))`, `Group(C₃)`, the coset `H = 1, r = [1,0]`); presentation independence (random generating sets of the same T1 group give identical bytes; random bases give identical bytes); `review_checks.group_bytes` agreement on all 40 T1 groups through the CLI; `Sym(5)` as rule 1 from two generators; `A₄` and `D₄` as rule 2.

### 3.5 Capacity and the `uint64` decision

Orders stay `uint64` in S4 (S3's admission refuses `|G| ≥ 2^64`). Rule 1's factorial product is the only place a larger integer could be needed, and overflow there decides the rule correctly. Record in `S4-notes.md` that `canon_nat` (detailed plan §2.1) is deferred to the slice that lifts the order limit, and that until then "exact multi-limb order" (§9.2) is satisfied only within `uint64`. The enumeration quota reuses `max_search_nodes` (document that it counts `visit` calls for enumeration objectives and `NODE` tokens for P1). The stabiliser consumer's chain rebuilds are bounded by `log₂|A|`; the transporter-coset objective runs two enumerations.

### 3.6 CLI and FORMAT

Subcommands: `min --order cdag|simple-upper`, `transporter --target-atoms ... | --target-arcs ...`, `stabiliser`, `transporter-coset`, each accepting the S1/S2 object options, `--backend`, `--max-nodes`, `--witness any|deterministic`. The FORMAT record becomes `case_id objective status trace_hex bytes_hex witness group_hex` (seven fields): `group_hex` holds `Group(H)` or `Group(H) || Perm(r₀)` for the stabiliser and coset objectives, the `SIMPLE-UPPER-1` key for a minimum under that order, and `-` otherwise; `bytes_hex` holds the minimum image's stream for minima; `witness` holds `g` for a minimum or transporter hit, `-` for an exhausted empty transporter. Update `refs/compare/FORMAT.md`, `compare.py` (`FIELDS`), the S1/S2 subcommands (emit `-`), and `tests/python/test_e2e.py` parsers.
