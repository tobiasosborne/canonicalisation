# tests/c

**Purpose.** C17 unit tests, built with the same strict warning flags as the library and run by `ctest` / `make test`.

**What may live here.** One `test_*.c` per topic, no external frameworks, exit status 0 on success. Tests may include internal headers from `src/` (the checker may not).

**Current tests.** `test_version.c` (version constants; the remaining stubs return `CANON_UNSUPPORTED_ACTION` even for NULL arguments, while the S1 entry points return `CANON_INVALID_INPUT` for NULL arguments), `test_header_abi.c` (static asserts: tag values, 8-member status enum, flag struct), and from slice S1: `test_perm.c` (§7.4 convention vectors, inverse/product identities on random permutations), `test_sort.c` (shared stable merge sort: order, stability, permutation), `test_wire.c` (U16/U32/B, §4.3 order, subset streams), `test_group_explicit.c` (|Sym(n)| = n! for n ≤ 5, |C₃| = 3, hand-computed `tuple_min`, capacity refusal), `test_partition.c` (split, individualisation, rollback, invariants), `test_search_subset.c` (the four §7.4 subset cases through the public API, capacity limits, invalid input, unsupported requests, `result_encode` and its sink, release in every order). From slice S2: `test_nat.c` (§4.1 `Nat` byte for byte), `test_graph.c` (import normalisation, label/colour order, invalid input and capacity, insertion-order independence, action and `(x^p)^q = x^(pq)`, equality, the simple wrapper), `test_graph_stream.c` (the §7.4 one-arc and the n = 1 loop cases through the public API, hand-derived streams), `test_signature.c` (sparse O-stage signatures and their comparison against a dense implementation in the test on random graphs and partitions; hand-built O-stage splits including §7.4's `[{1},{0}]`), `test_simple_upper.c` (§4.4 keys for n = 0..5, class rejections), `test_search_graph.c` (the §7.4 graph case through the API, capacity limits, a graph fixed by its group, equivariance and witness validity, invalid input, workspace reuse across kinds, the trace-first leaf counters, no borrowed pointer after a run, releasing an object before reusing the workspace). From slice S3: `test_chain.c` (the side of the transporter, the sift and the §7.2 step on a 3-cycle and a transposition; all 40 T1 groups and 200 random T2 generator sets with `n ≤ 8` against the explicit backend: order, membership of every element of `Sym(n)` and random non-members, `tuple_min` `t` and orbit ids for lists of every length, rebase to random prefixes, verification; `Sym(12)`, the 64-cycle, `Sym(20)`/`Sym(21)` capacity, the backend option and `canon_group_order`; prints the construction counters), `test_verify.c` (ten mutations of a verified chain, each rejected with the matching reason, further reasons, and the non-nested `Sym(3)` chain), `test_provenance.c` (record kinds and product side, re-derivation of every strong generator, the DAG size bound), `test_reference_schreier.c` (the §9.1 recursion against the chain on T1). `t1_groups.h` enumerates the T1 subgroups with their greedy generators. `check.h` is the shared assertion helper (with `check_hex_is` since S2).

**Governing spec sections.** §3 and §3.2 (tags, statuses, flags), §§4.1-4.3, §7, §10, §11.1, §17 (API), §20.
