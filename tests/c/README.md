# tests/c

**Purpose.** C17 unit tests, built with the same strict warning flags as the library and run by `ctest` / `make test`.

**What may live here.** One `test_*.c` per topic, no external frameworks, exit status 0 on success. Tests may include internal headers from `src/` (the checker may not).

**Current tests.** `test_version.c` (version constants; the remaining stubs return `CANON_UNSUPPORTED_ACTION` even for NULL arguments, while the S1 entry points return `CANON_INVALID_INPUT` for NULL arguments), `test_header_abi.c` (static asserts: tag values, 8-member status enum, flag struct), and from slice S1: `test_perm.c` (§7.4 convention vectors, inverse/product identities on random permutations), `test_sort.c` (shared stable merge sort: order, stability, permutation), `test_wire.c` (U16/U32/B, §4.3 order, subset streams), `test_group_explicit.c` (|Sym(n)| = n! for n ≤ 5, |C₃| = 3, hand-computed `tuple_min`, capacity refusal), `test_partition.c` (split, individualisation, rollback, invariants), `test_search_subset.c` (the four §7.4 subset cases through the public API, capacity limits, invalid input, unsupported requests, `result_encode` and its sink, release in every order). From slice S2: `test_nat.c` (§4.1 `Nat` byte for byte), `test_graph.c` (import normalisation, label/colour order, invalid input and capacity, insertion-order independence, action and `(x^p)^q = x^(pq)`, equality, the simple wrapper), `test_graph_stream.c` (the §7.4 one-arc and the n = 1 loop cases through the public API, hand-derived streams), `test_signature.c` (sparse O-stage signatures and their comparison against a dense implementation in the test on random graphs and partitions; hand-built O-stage splits including §7.4's `[{1},{0}]`), `test_simple_upper.c` (§4.4 keys for n = 0..5, class rejections), `test_search_graph.c` (the §7.4 graph case through the API, capacity limits, a graph fixed by its group, equivariance and witness validity, invalid input, workspace reuse across kinds, the trace-first leaf counters, no borrowed pointer after a run, releasing an object before reusing the workspace). From slice S3: `test_chain.c` (the side of the transporter, the sift and the §7.2 step on a 3-cycle and a transposition; all 40 T1 groups and 200 random T2 generator sets with `n ≤ 8` against the explicit backend: order, membership of every element of `Sym(n)` and random non-members, `tuple_min` `t` and orbit ids for lists of every length, rebase to random prefixes, verification; `Sym(12)`, the 64-cycle, `Sym(20)`/`Sym(21)` capacity, the backend option and `canon_group_order`; prints the construction counters), `test_verify.c` (ten mutations of a verified chain, each rejected with the matching reason, further reasons, and the non-nested `Sym(3)` chain), `test_provenance.c` (record kinds and product side, re-derivation of every strong generator, the DAG size bound), `test_reference_schreier.c` (the §9.1 recursion against the chain on T1). From slice S4: `test_coset_least.c` (the product side `J r` on a transposition and a 3-cycle; every T1 group, every `r`, random constraint sets and every chain level against the element tables; random groups with `n ≤ 7` whose elements come from the explicit backend's enumerator; the least element of `H \ K` for every T1 pair `K ≤ H`; invalid arguments), `test_enumerate.c` (the hand-derived leaf sequence of `Sym(3)` that pins `t_b r`; leaves are exactly `G`, each once, on all T1 groups and 100 random groups, with identical leaf sequences and node counts for both backends; the quota at the exact boundary, stop on request and cancellation at the same point for both backends; `C_2^17` beyond the explicit table; prints node and rebuild counters), `test_group_stream.c` (the four §7.4 payloads; every T1 group against a brute-force evaluation of §9.4; presentation and base independence on T1 and random groups; `Sym(5)` by rule 1, `A₄` and `D₄` by rule 2; `2^k ≤ |H|`; coset payloads against brute force; the output bound), `test_objectives.c` (each objective through the public API: §7.4's minimum `{0}` versus P1's `{1}`, transporter hit and proved empty, stabilisers, the coset payload and `r₀`, `SIMPLE-UPPER-1` and its key; the deterministic witness equals the least leaf witness on every T1 case under both backends; `verify_witness` accepts engine witnesses and rejects tampered ones; validation of targets, combinations, the §4.4 class and options; quota, output bounds, results outliving their problem, workspace reuse; prints the stabiliser objective's T1 counters). From slice S5: `test_dag.c` (interning, set deduplication, multiset merging and its 64-bit overflow, unreachable discard, height numbering and within-height order, the §7.4 `(b,b)` case, the depth-60 shared chain with 61 records and a fully duplicated depth-10 tree, sets of sets, insertion-order and sharing independence on random DAGs, idempotence, encode-decode-normalise identity, the general encoder against the S1 subset and S2 graph streams, canonical Group and coset payloads from other presentations, nested graphs unsupported, the acyclicity check and module contracts, and the output-size argument: exact for tags 01-06 on random DAGs, a bound for subgroup leaves with the concrete C4 case of 77 against 41 bytes), `test_cdag_decode.c` (every rejection rule of `tools/hexdump_stream.py` plus the stricter ones, each with its status and reason; round trips and every truncation of twelve canonical streams; what import accepts and the validator refuses; limits; 3000 random bit flips), `test_dag_action.c` (the conjugation side `g⁻¹pg`, pinned with a `g` of order 3 because the brief's `g = [0,2,1]` is an involution; the §7.4 cycle vector; re-sorted nested records; `(x^p)^q = x^(pq)` and an independent image construction on random DAGs with every leaf type; presentation-independent subgroup payloads and the coset action against brute force), `test_search_dag.c` (`canon_object_create` statuses and limits, the §7.4 `(b,b)` case through the API, subsets and graphs imported from non-canonical streams against the builders on every T1 group, P1 on nested roots: the empty-subset trace, equivariance over every group element, verified witnesses, the deterministic witness, validated outputs, the S4 objectives on nested objects; capacity at problem creation including the subgroup-leaf bound; workspace reuse across kinds). `t1_groups.h` enumerates the T1 subgroups with their greedy generators. `check.h` is the shared assertion helper (with `check_hex_is` since S2).
