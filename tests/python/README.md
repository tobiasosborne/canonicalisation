# tests/python

**Purpose.** `unittest` tests for data and tools (no pytest, no pip installs).

**Run.** `nice -n 19 python3 -m unittest discover -s tests/python -q` from the repository root, after `make` (`test_e2e.py` needs the CLI: it reads `CANON_CLI`, else `build/make/canon-cli`; without a built CLI its tests skip with a message, unless `CANON_REQUIRE_CLI=1`, which `make check`, `ctest` and CI set, turns the skip into a failure).

**Tests.** `test_golden_vectors.py` recomputes each entry of `refs/vectors/golden.json` with `checks/review_checks.py` (P1 trace, stream and witness; group and coset payloads; convention vectors; signed and labeling examples). `test_hexdump_stream.py` parses the six spec §7.4 streams and malformed variants with `tools/hexdump_stream.py`. `test_e2e.py` (slice S1) runs `canon-cli` over every subgroup of `Sym(n)`, `n ≤ 4`, and every subset with two generating sets (full element list and greedy sequence), comparing trace, bytes and witness with `checks/review_checks.p1` and with each other, checks that the witness is the spec §3 deterministic witness, runs the subset entries of `golden.json`, and checks the §11.1 node quota, invalid input and usage errors. Slice S2 adds the graph tiers G1 (n ≤ 2, every subgroup, every multiplicity vector in {0,1,2}^(n·n), colours all empty and distinct) and G2 (n = 3, 4, every subgroup, 40 seeded random labelled, coloured multigraphs per group), each compared field by field with `review_checks.p1(..., "graph", ...)` under both generating sets, with the arcs shuffled and partly split into duplicates on the CLI side, every emitted stream parsed by `tools/hexdump_stream.py`; plus the §7.4 graph entry of `golden.json`, a graph whose leaves are partly skipped by the trace-first rule, a huge degree (`CAPACITY_LIMIT` for both subcommands), a graph node quota and `p1-graph` usage errors.

Slice S3: `CANON_BACKEND=chain|explicit` makes every CLI call of `test_e2e.py` pass `--backend`; `make check` and `ctest` (`test_e2e_explicit`) run the file again with the explicit backend, and both runs must agree with the model. The `Backends` class checks the option itself and a group of order 131072 that only the chain backend admits.

**Governing spec sections.** §7.4 (golden cases), §4.1 (wire grammar), §9.4 (Group payload), §20.
