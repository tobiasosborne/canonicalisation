# refs/oracle

**Purpose.** A tiny exhaustive oracle (spec §20): on small domains it enumerates the whole group and checks all orbit values, lexicographic minima, complete stabilisers, transporters, characters and reference tree keys by brute force. It is independent of both blind implementations and of the production code.

**`oracle.py`** (work package M0a, `docs/slices/M0a.md`; detailed plan WP0.3). `python3 refs/oracle/oracle.py CASEFILE RECORDS [--max-order N] [--verbose]` reads a case file of `refs/CASES.md` and a FORMAT file (`refs/compare/FORMAT.md`) and checks every record whose group has at most `--max-order` elements (default 200 000) against the definitions: orbit membership of the bytes, the witness in `G` with the right action (and the least solution in deterministic mode), the least image under `CDAG-BYTE-1` or `SIMPLE-UPPER-1`, `Group(A)` and `Group(A) || Perm(r₀)` by the §9.4 rules, `λ ∈ Gρ` and `Aλ`, the character by the §8.4 lift (zero iff an odd automorphism exists, `s = χ(t)`), and across the file the invariances `C_G(x^h) = C_G(x)` (bytes and trace), `c` under a representative change `kρ`, and `s(x^h) = χ(h)s(x)`. Statuses: an inconsistent character must be `INVALID_INPUT`, a signed labeling problem and an objective outside M0 `UNSUPPORTED_ACTION`; `CAPACITY_LIMIT` records are skipped; a transporter whose target has another shape is an ordinary empty case (M0a decision 4). Traces are otherwise not checked: they are defined by P1, not by the orbit, and only the two references check each other's traces. Every failure names the case and the rule; exit 1 on any failure or missing record.

**Since the independent review (19 October 2026, `docs/slices/M0a-notes.md`).** `SIMPLE-UPPER-1` on an object outside the spec §4.4 class must be `UNSUPPORTED_ACTION` (before, the oracle demanded `COMPLETE` first, so no record could pass); `CAPACITY_LIMIT` is a failure when the case's quota is at least `work_bound(n, |G|)` (the unpruned P1 tree's `Σ_d n!/(n−d)!` nodes plus two §8.1 enumerations of `2|G| − 1` visits each), so on T1 and T2 under the default quota every case must be `COMPLETE`, and is skipped otherwise; a labeling-coset leaf is the value `(H, least element of H r)`, so equal cosets given by different representatives are one node. **Not checked**, by design: the trace beyond being non-empty and invariant, which orbit element a canonical or signed image is (both are P1's choice), which odd automorphism a certified zero reports in `any` mode, and the hex fields of a skipped `CAPACITY_LIMIT` record. The invariance rules compare cases present in one file; `tools/gen_cases.py` appends the transported copies and representative changes they need.

**What it may use.** Its CDAG-2 encoder (tags 01–09), §4.2 normaliser, `Group(H)`, `Perm` and `SIMPLE-UPPER-1` writers are written from the spec text in this file. It imports only `closure`, `mul` and `inverse` from `checks/review_checks.py` (WP0.3), never `p1`, `dag_bytes`, `graph_bytes` or `group_bytes`. Standard library otherwise.

**Range.** Deliberately naive: the orbit of every case is enumerated and encoded (cached per object across the objectives of a case file), so a group of order 2·10⁵ costs seconds per object; beyond `--max-order` cases are skipped and counted. ref-a and ref-b must agree with each other on the larger generated cases (T3), which this oracle cannot check.

**Tests.** `tests/python/test_refs.py` (the golden cases and a seeded T2 sample through ref-a accepted; corrupted witnesses, minima and groups rejected).

**Governing spec sections.** §20 (separate tiny exhaustive oracle), §3 (objectives and conventions), §3.1 (labeling cosets), §4.1–4.4 (encoding and orders), §8.2 (consumers), §8.4 (characters, signed objective), §9.4 (`Group(H)`).

**Since spec v2.2 (19 October 2026, maintainer decision D1, `HANDOFF.md`).** In the deterministic mode a certified signed zero must report the least image-array element of `A = Aut_G(x)` with `χ = −1` (spec v2.2 §3), found by explicit enumeration; any other odd automorphism fails with "deterministic zero witness is not the least odd element of A".
